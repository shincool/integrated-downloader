# 통합 다운로더

YouTube · Instagram · TikTok 주소를 붙여넣으면 영상·음원·사진을 받아 주는 **내 PC 전용** 웹 화면입니다.
[yt-dlp](https://github.com/yt-dlp/yt-dlp)와 [gallery-dl](https://github.com/mikf/gallery-dl)을 쉽게 쓰도록 감싼 프로그램이에요.

- 주소를 넣으면 제목·썸네일·길이·화질 목록을 먼저 보여 줘요
- 영상(MP4, 화질 선택) 또는 음원(MP3)으로 받기
- 인스타 여러 장 게시물·사진 게시물도 한 번에 받기
- 받은 파일을 `채널_날짜_제목 [아이디]` 이름으로 한 폴더에 자동 정리 (끄면 브라우저로 바로 내려받기)
- 서버는 `127.0.0.1` 에서만 열려서 같은 와이파이의 다른 기기에서도 접속할 수 없어요

> Windows 10 / 11 기준으로 만들었어요.

## 설치

1. **Python 3.10 이상** — <https://www.python.org/downloads/>
   설치 첫 화면에서 **"Add python.exe to PATH"** 에 꼭 체크하세요.
2. **FFmpeg** — 고화질 영상 합치기와 MP3 변환에 필요해요. 명령 프롬프트에서:
   ```
   winget install Gyan.FFmpeg
   ```
3. **Node.js** — 일부 YouTube 영상의 화질 목록을 풀 때 필요해요.
   ```
   winget install OpenJS.NodeJS.LTS
   ```
4. 이 저장소를 받으세요. 초록색 **Code → Download ZIP** 을 누르고 압축을 풀면 돼요.

## 실행

압축을 푼 폴더의 **`run.bat`** 을 더블클릭하세요.

- 처음에는 필요한 부품을 설치하느라 1~2분 걸려요.
- 브라우저가 `http://127.0.0.1:5000` 으로 자동으로 열려요.
- 쓰는 동안 까만 창을 닫지 마세요. 창을 닫으면 프로그램이 꺼져요.
- 실행할 때마다 yt-dlp 를 최신으로 맞춰요. YouTube 가 바뀌면 옛 버전은 자주 고장 나거든요.

## 받은 파일은 어디에?

- **"채널백업에 바로 저장"이 켜져 있으면:** `내 다운로드\채널백업` 폴더에 쌓여요.
  다른 곳에 두려면 처음 실행 후 생기는 `channels.json` 의 `"root"` 를 바꾸세요. 예: `"root": "D:\\채널백업"`
- **꺼져 있으면:** 브라우저의 다운로드로 바로 받아져요.

## 로그인이 필요한 경우 (인스타 사진·비공개 게시물)

화면의 **로그인** 칸에서 고르세요.

| 선택 | 설명 |
|---|---|
| Firefox 로그인 사용 | Firefox 에 로그인돼 있으면 가장 잘 돼요 |
| Edge / Chrome 로그인 사용 | 브라우저를 완전히 끈 뒤 시도하세요. 최신 버전은 막혀 있을 수 있어요 |
| cookies.txt 파일 사용 | 브라우저 확장으로 내보낸 `cookies.txt` 를 이 폴더에 넣으세요 |

> **`cookies.txt` 는 내 계정 로그인 정보예요. 다른 사람에게 보내거나 인터넷에 올리지 마세요.**

### 선택 기능: 로그인 없이 인스타 사진 받기

브라우저를 몰래 띄워서 사진을 모으는 방식이에요. 쓰려면 명령 프롬프트에서 이 폴더로 이동한 뒤:

```
.venv\Scripts\python.exe -m pip install playwright
.venv\Scripts\python.exe -m playwright install chromium
```

## 자주 묻는 것

- **"정보를 가져오지 못했습니다"** — `run.bat` 을 다시 실행해서 yt-dlp 를 최신으로 맞춰 보세요.
- **영상과 소리가 따로 받아져요 / MP3 가 안 돼요** — FFmpeg 가 설치되지 않은 거예요.
- **인스타가 로그인을 요구해요** — 위의 로그인 설정을 켜세요.
